# Design Brief: PG Management System

## Purpose
To provide an intuitive, modern, and professional interface for the property management platform, ensuring efficient workflow and a pleasing user experience.

## Scope
- Redesign page headers such as "Properties Management" across all views for improved clarity, consistency, and visual polish.
- Core features: Dashboard, properties, tenants, invoices, payments, allocations.

## Success Criteria
- All primary headers (e.g., "Properties Management", "Tenant Management") appear visually consistent and highly professional.
- Improved readability and accessibility (especially for large sections and navigation).
- Visual alignment with modern UI/UX patterns.

## Target Audience
- Property managers, staff, and administrators seeking an efficient management tool.

## User Objectives
- Instantly understand which section is in view.
- Enjoy a visually appealing, uncluttered workspace.

## Primary Features
- Bold, easily scannable section/page headers.
- Consistent header placement and spacing.
- Clearly differentiated from body and card titles.
- Subheaders or breadcrumbs for contextual navigation (optional).

## Calls to Action
- Section-specific actions (e.g., "+ Add Property" next to header).

## Visual Style (Header guidance)
- Large font (responsive: clamp between 2rem and 2.8rem).
- Strong font-weight (600+).
- Adequate padding/margin below and above.
- Use primary brand color or neutral with a subtle accent/border.
- Consider icons or visual cues for polish.
