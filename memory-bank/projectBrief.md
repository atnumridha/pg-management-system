# Project Brief

## Project Name
Paying Guest Management System

## Foundation and Purpose
This project is a comprehensive management system designed to streamline operations for paying guest (PG) accommodations. It covers both backend and frontend components for property, tenant, room, allocation, and payment management.

## Core Requirements and Goals
- Digital management for PG properties, tenants, rooms, allocations, invoices, and payments.
- Robust backend (Java, Spring Boot) and frontend (Angular).
- Role-based access: Admin and employees.
- Data integrity, reliability, and scalability.
- UX focused on simplicity and efficiency for both operators and tenants.

## Project Scope
- Tenant onboarding, property and room management, allocations, rent/invoice tracking, and payment logging.
- Admin dashboard, reporting, and analytics.
- APIs for integration with other systems.
- Secure authentication and authorization.
